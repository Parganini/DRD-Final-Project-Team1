## Set Working Directory

To run the scripts be sure to set the working directory as the root folder of the repository:

```r
setwd('...../GitHub/drd-final-project-team1')
```

## Running individual scripts

To run individual scripts inside R studio use:

```r
source("scripts/XX_script.R")
```

## Running the whole pipeline

To run the whole pipeline run the file `run_pipeline.R` :

```r
source("scripts/run_pipeline.R")
```
